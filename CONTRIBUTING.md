# Contributing to TraderAI

Thanks for your interest! TraderAI is a self-hosted, bring-your-own-keys
trading intelligence platform. Contributions welcome.

## Getting started

```bash
pip install -r requirements.txt
cp .env.example .env          # add your keys (only ANTHROPIC_API_KEY needed for AI)
python -m uvicorn api:app --app-dir backend --reload --port 8000
cd frontend && npm install && npm run dev
```

## Ground rules

- **Tests must pass**: `pytest tests/ -q` (also runs in CI). New engine logic
  needs tests; the suite runs offline - mock network calls.
- **No secrets, ever**: `.env`, `positions.json`, and all financial-data caches
  are gitignored. Never commit real portfolio data or API keys.
- **AI calls go through `ai_client.py`** - it enforces the user's daily budget
  cap and model tier. Never instantiate an Anthropic client elsewhere.
- **AI degrades gracefully**: every AI feature must work (or step aside
  cleanly) without keys.
- **Grounded numbers only**: the AI never states a price/score it didn't get
  from a tool; new signals should be computed by code, not generated by a model.
- **Frontend**: plain JSX + shadcn/ui + Tailwind v4, monochrome theme - color
  is reserved for P&L semantics (text-gain / text-loss / text-warn).

## Not investment advice

This project is analysis tooling for personal use. PRs that market it as
financial advice, auto-execute trades against brokerages, or redistribute
licensed market data will be declined.
